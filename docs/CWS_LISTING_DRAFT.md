# Chrome Web Store listing draft

**Name:** CleanX

**Summary:** A quieter X. Hide videos, images, and GIFs with placeholders. Keep media from the people you choose.

**Description:**

CleanX gives you three switches for the media in your X feed. Hide videos,
images, or GIFs and keep the post's text in view. Click a placeholder whenever
you want to see an item, then hide it again with one click.

Add usernames to always show media from those authors. Quotes follow the quoted
author's own preference. Avatars and profile banners stay visible.

The popup shows your current X page and how many media items are hidden in its
loaded content. Your choices apply across X tabs and stay saved on your device.
CleanX is active only on x.com, with English text and automatic light/dark themes.

No accounts, analytics, cloud service, or runtime UI dependencies. CleanX hides
media and pauses blocked videos; X may still fetch the media itself.

**Single purpose:** Control the visibility of post media on x.com.

**Permission justification:** See [architecture](architecture.md#permissions).

**Privacy policy:** Publish the [policy](PRIVACY_POLICY.md) at an accessible URL
when preparing the store submission.

verified UI captures using fictional posts. Store-specific promotional images
